# PULSE

Премиальное приложение для управления временем: задачи, календарь, фокус,
привычки и серия дней — в одном спокойном интерфейсе.

**Платформа:** iPhone (iOS 17+) и iPadOS. Написано на SwiftUI, без сторонних
зависимостей, полностью офлайн. Сборка — на GitHub Actions, потому что Mac нет.

Дизайн-система, информационная архитектура и логика описаны в [DESIGN.md](DESIGN.md).

---

## Что внутри

| Раздел | Возможности |
|---|---|
| **Сегодня** | Приветствие, прогресс дня кольцом, задачи, ближайшее событие с обратным отсчётом, свободное время, привычки, серия, расписание |
| **Календарь** | Месяц / неделя / день, загрузка дней, цветные категории, свободные окна, перенос задач перетаскиванием на другую дату |
| **Задачи** | Умные списки (сегодня, завтра, неделя, просрочено, без даты, выполнено), поиск, фильтр по категориям, подзадачи, приоритеты, повторения, умное распределение по свободным окнам |
| **Фокус** | Таймер на 25/5/15 минут с настройкой, привязка к задаче, режим «без отвлечений», история сессий, счётчик цикла до длинного перерыва |
| **Аналитика** | Динамика по дням/месяцам, распределение по категориям (донат), план против факта, лучшие дни недели, тепловая карта активности за 16 недель, личные рекорды |
| **Серия** | Анимированный огонёк, текущая и лучшая серия, достижения за 7/14/30/60/100/365 дней, календарь успешных дней, привычки, дни отдыха, восстановление серии |
| **Настройки** | Светлая/тёмная/системная тема с плавным переходом, 4 акцента, цели, длительности фокуса, начало недели, напоминания, демо-данные, полный сброс |

Дополнительно: онбординг с выбором имени и темы, тактильная отдача (haptics),
локальные напоминания, автосохранение данных, поддержка iPad с боковой
навигацией и двухпанельными экранами.

## Структура

```
project.yml                  # проект Xcode генерируется через XcodeGen
Support/Info.plist           # Info.plist (вне Sources, чтобы не попал в ресурсы)
Sources/
  App/                       # точка входа, RootView, Router, таб-бар, iPad-сайдбар
  Core/                      # модели, хранилище, движки серии и статистики, демо-данные
  Design/                    # тема, компоненты, эффекты, строки списков
  Screens/                   # Today, Calendar, Tasks, Focus, Insights, Streak,
                             # редакторы, настройки, онбординг
  Resources/Assets.xcassets  # иконка, акцентный цвет, цвет запуска
Tools/make_icon.py           # генерация иконки 1024×1024
Tools/check_sources.py       # механические проверки исходников
.github/workflows/build.yml  # сборка unsigned .ipa
```

## Сборка на GitHub Actions

1. Запушь репозиторий в GitHub (ветка `main`).
2. Actions → workflow **Build PULSE** запустится сам на push.
3. В логах: `xcodegen generate` → `xcodebuild archive` → `zip` в `Payload/` → артефакт `PULSE-unsigned-ipa`.
4. Готовый файл также публикуется в релиз `latest`:
   `https://github.com/Lscost13/pulse/releases/download/latest/PULSE-unsigned.ipa`

Сборка без сертификатов (`CODE_SIGNING_ALLOWED=NO`), поэтому .ipa **неподписанный** —
подпись делается при установке с компьютера.

### Как запушить (Windows, без GitHub CLI)

1. Создай на GitHub **пустой** репозиторий (без README и .gitignore).
2. В папке проекта:

```powershell
.\Tools\push.ps1 https://github.com/Lscost13/pulse.git
```

Вручную то же самое:

```powershell
git init -b main
git add -A
git commit -m "PULSE"
git remote add origin https://github.com/Lscost13/pulse.git
git push -u origin main
```

При первом push Git попросит логин и **personal access token** вместо пароля
(Settings → Developer settings → Tokens (classic) → scope `repo` **и `workflow`** —
без `workflow` GitHub откажется принимать файл `.github/workflows/build.yml`).

## Установка на iPhone 15

iPhone 15 (A16) не поддерживает TrollStore, поэтому подпись — через Sideloadly
или AltStore с твоим Apple ID.

1. Скачай [Sideloadly](https://sideloadly.io) на Windows и установи.
2. Скачай `PULSE-unsigned.ipa` из релиза `latest`.
3. Подключи iPhone кабелем, разреши «Доверять этому компьютеру».
4. В Sideloadly: перетащи .ipa, введи Apple ID (для платного аккаунта — тот же),
   нажми Start.
5. На iPhone: Настройки → Основные → VPN и управление устройством →
   «Доверять» разработчику.
6. Запускай PULSE.

**Срок подписи:** с платным Apple Developer ($99/год) профиль живёт 1 год,
с бесплатным Apple ID — 7 дней (потом просто переподписать тем же способом,
данные в приложении сохранятся).

## Локальная сборка (если появится Mac)

```bash
brew install xcodegen
xcodegen generate
open PULSE.xcodeproj
```

Deployment target — iOS 17.0, устройства 1,2 (iPhone + iPad), Swift 5.

## Технические решения

- **Состояние:** `@Observable` класс `AppStore` — единый источник истины, внедряется через `.environment`.
- **Хранение:** один JSON-снапшот в `Application Support/PULSE/store.json` (`Codable`, атомарная запись). Никакой сети, аккаунтов и телеметрии.
- **Даты:** собственная русская локализация календаря (`RuCal`), а не системная — чтобы подписи не зависели от настроек устройства.
- **Графики:** нарисованы вручную (формы, `trim`, `Capsule`) — без Charts и внешних пакетов, чтобы сборка была стабильной.
- **Уведомления:** `UNUserNotificationCenter`, локальные, только по задачам.

## Чего пока нет (осознанно)

- Виджеты, Live Activity, iCloud-синхронизация — требуют app extension и entitlements,
  что усложняет подпись на бесплатном/личном аккаунте. Следующий шаг после базовой установки.
- Экспорт/импорт данных, Apple Calendar — кандидаты на следующую версию.

## Изменить bundle id

`project.yml` → `PRODUCT_BUNDLE_IDENTIFIER: com.pulse.app`. Он же определяет,
какой профиль подписи нужен для установки.
